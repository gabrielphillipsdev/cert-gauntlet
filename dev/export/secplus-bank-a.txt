[a001] type=mc domain=4 obj=4.8 (Explain appropriate incident response activities) cat=ir
Q: A regional hospital's SOC confirms that a nurse's workstation is beaconing to a known ransomware staging server. The analyst has verified the alert is not a false positive. Which of the following should the analyst do NEXT?
  * A. Isolate the workstation from the network to stop the spread
        why: Once detection and analysis have confirmed a real incident, containment comes next. Isolating the host prevents lateral movement and encryption of shared clinical drives.
    B. Reimage the workstation from the hospital's golden image
        why: Reimaging is eradication/recovery. Doing it before containment and evidence capture destroys forensic data and does nothing to stop other hosts that may already be infected.
    C. Schedule a lessons-learned meeting with clinical leadership
        why: Lessons learned is the final phase, held after recovery. Holding it now leaves an active beacon running on the network.
    D. Run a full vulnerability scan of the clinical VLAN
        why: Scanning is a preparation or validation activity. It would delay containment and could disrupt medical devices during an active incident.
TAKEAWAY: IR order: preparation, detection, analysis, containment, eradication, recovery, lessons learned. Once an incident is confirmed, contain it before you clean it up.

[a002] type=mc domain=2 obj=2.4 (Given a scenario, analyze indicators of malicious activity) cat=attacks
Q: A software company's web application firewall records the request shown below against the customer portal. Which of the following attacks is being attempted?
EXHIBIT:
    GET /account?id=1042%27%20OR%20%271%27%3D%271 HTTP/1.1
    Host: portal.example.net
    User-Agent: Mozilla/5.0
    (decoded: /account?id=1042' OR '1'='1)
  * A. SQL injection
        why: The single quote followed by OR '1'='1 is a classic tautology that makes a database WHERE clause always true. The attacker is trying to dump every account row instead of id 1042.
    B. Cross-site scripting
        why: XSS payloads contain script tags or event handlers aimed at other users' browsers; this payload is targeting the back-end query, not the browser.
    C. Directory traversal
        why: Traversal uses ../ sequences to escape the web root and read files. Nothing in this request references file paths.
    D. Cross-site request forgery
        why: CSRF tricks a logged-in user's browser into sending an unwanted request. This is a crafted parameter value sent directly by the attacker, not a forged user action.
TAKEAWAY: A quote plus OR '1'='1 in a parameter is the signature of SQL injection. Input validation and parameterized queries are the fix.

[a003] type=mc domain=5 obj=5.2 (Explain elements of the risk management process) cat=gov
Q: A hospital risk analyst values the MRI scheduling system at $2,000,000. A ransomware event is expected to affect 10% of that value and is estimated to occur once every four years. Which of the following is the annualized loss expectancy?
  * A. $50,000
        why: SLE = $2,000,000 × 0.10 = $200,000. ARO = 1/4 = 0.25. ALE = $200,000 × 0.25 = $50,000.
    B. $200,000
        why: $200,000 is the single loss expectancy (asset value × exposure factor), not the annualized figure. It must still be multiplied by ARO.
    C. $800,000
        why: This multiplies the SLE by 4 as if the event happened four times a year. Once every four years is an ARO of 0.25, not 4.
    D. $500,000
        why: This multiplies the full asset value by 0.25 and ignores the 10% exposure factor. Only the exposed portion is lost per event.
TAKEAWAY: SLE = AV × EF; ALE = SLE × ARO. An event every N years has an ARO of 1/N.

[a004] type=mc domain=3 obj=3.1 (Compare and contrast security implications of different architecture models) cat=arch
Q: A K-12 school district moves its student information system to a cloud provider's IaaS offering. The district's own staff install and manage the Linux virtual machines and database software. A critical kernel vulnerability is announced. Which of the following is responsible for patching it?
  * A. The school district, because the guest operating system is the customer's responsibility in IaaS
        why: In IaaS the provider secures the hypervisor and physical hosts; everything from the guest OS upward belongs to the customer. The district must patch its own VMs.
    B. The cloud provider, because it owns the physical servers running the virtual machines
        why: The provider patches the hypervisor and hardware firmware, not the guest kernel inside a customer-managed VM.
    C. The database vendor, because the vulnerability affects the system hosting its product
        why: A database vendor supports its own software. It has no role in the operating system beneath it.
    D. Neither party, because IaaS virtual machines are isolated from kernel exploits
        why: Virtualization does not remove OS vulnerabilities; an unpatched guest kernel is fully exploitable from inside the VM.
TAKEAWAY: Shared responsibility: IaaS = customer owns the guest OS and up; PaaS = customer owns application and data; SaaS = customer owns data and access.

[a005] type=mc domain=1 obj=1.2 (Summarize fundamental security concepts) cat=controls
Q: A hospital is adopting a zero trust architecture. A physician's tablet requests access to the imaging archive. One component evaluates the physician's role, the tablet's compliance state, and current threat intelligence and decides to allow the session. Which of the following zero trust components made that decision?
  * A. Policy engine
        why: The policy engine is the control-plane brain that evaluates identity, device posture, and context against policy and renders the allow/deny decision.
    B. Policy enforcement point
        why: The PEP sits in the data plane and merely opens or closes the path to the imaging archive after being told the decision; it does not weigh the inputs itself.
    C. Policy administrator
        why: The policy administrator is also in the control plane, but it relays the engine's decision to the enforcement point and manages the session rather than deciding.
    D. Implicit trust zone
        why: An implicit trust zone is the small data-plane segment where traffic is allowed after a decision has been made; it is a place, not a decision-making component.
TAKEAWAY: Zero trust control plane: policy engine decides, policy administrator communicates the decision. Data plane: policy enforcement point applies it; subjects and implicit trust zones live there.

[a006] type=mc domain=4 obj=4.6 (Given a scenario, implement and maintain identity and access management) cat=iam
Q: A software company wants its engineers to sign in to a third-party bug-tracking SaaS using their corporate identity provider. The SaaS must receive a signed XML assertion listing the user's identity and group memberships, and the corporate password must never be sent to the SaaS. Which of the following should be implemented?
  * A. SAML federation with the company as the identity provider
        why: SAML exchanges signed XML assertions between an identity provider and a service provider, delivering identity and attributes without the SP ever seeing the password.
    B. OAuth 2.0 with the SaaS acting as the resource server
        why: OAuth is an authorization framework that issues access tokens for delegated API access; it does not itself deliver a signed XML identity assertion.
    C. LDAP bind from the SaaS to the corporate directory
        why: An LDAP bind would require the SaaS to receive and forward the user's password to the directory, which violates the requirement.
    D. RADIUS with EAP-TLS between the SaaS and the identity provider
        why: RADIUS is for network access authentication (VPN, Wi-Fi, switch ports), not for browser-based SSO into a web application.
TAKEAWAY: SAML = XML assertions for web SSO between IdP and SP. OAuth = delegated authorization tokens. OIDC = identity layer on OAuth using JSON tokens.

[a007] type=mc domain=2 obj=2.1 (Compare and contrast common threat actors and motivations) cat=actors
Q: A hospital's research department stores unpublished clinical trial data. Investigators find a long-running, quiet intrusion that used custom malware, several previously unknown exploits, and exfiltrated only trial results over 14 months. No ransom demand or data sale has been observed. Which of the following threat actors is MOST likely responsible?
  * A. Nation-state actor motivated by espionage
        why: Custom tooling, multiple zero-days, patience over 14 months, and interest only in research data with no monetization are the hallmarks of a well-resourced state espionage campaign.
    B. Organized crime group motivated by financial gain
        why: Criminal groups monetize quickly through ransom, extortion, or sale of data. Fourteen months of silent collection with no cash-out does not fit.
    C. Hacktivist motivated by philosophical beliefs
        why: Hacktivists seek publicity through defacement, leaks, or disruption. A covert, unpublicized intrusion is the opposite of their goal.
    D. Unskilled attacker using downloaded tools
        why: Unskilled attackers rely on public tools and known exploits; they do not develop custom malware or possess multiple zero-day exploits.
TAKEAWAY: Match actor to resources and motivation: zero-days plus patience plus data-only interest = nation-state espionage.

[a008] type=mc domain=5 obj=5.3 (Explain the processes associated with third-party risk assessment and management) cat=third
Q: A school district is choosing a vendor to host student records. One candidate offers a report in which an independent accounting firm tested the vendor's security controls over a 12-month period and gave an opinion on their effectiveness. Which of the following vendor assessment methods does this report represent?
  * A. Independent third-party assessment
        why: A report issued by an outside firm that tested the vendor's controls is an independent assessment. It gives the district assurance without having to audit the vendor itself.
    B. Evidence of internal audits
        why: Internal audit evidence is produced by the vendor's own staff. This report was produced by an outside accounting firm, which carries more weight.
    C. Right-to-audit clause
        why: A right-to-audit clause is a contract term letting the district perform its own inspection. Here the district is relying on someone else's completed report.
    D. Supply chain analysis
        why: Supply chain analysis examines the vendor's own suppliers and dependencies, not the vendor's control effectiveness over a test period.
TAKEAWAY: Vendor due diligence tools: independent third-party assessment reports, evidence of internal audits, right-to-audit clauses, questionnaires, and pen test results.

[a009] type=mc domain=3 obj=3.3 (Compare and contrast concepts and strategies to protect data) cat=data
Q: A software company's developers need realistic customer records to test a new billing feature. Compliance requires that no real names, card numbers, or addresses ever reach the development environment, but the data must keep its format so that validation code works. Which of the following BEST meets this requirement?
  * A. Data masking that replaces sensitive fields with realistic substitute values
        why: Masking swaps real values for format-preserving fake ones, so developers get usable test data while no actual PII leaves production.
    B. Encrypting the production database export before copying it to development
        why: Encryption protects the copy in transit, but developers would decrypt it to use it, so real PII would still land in the development environment.
    C. Hashing every sensitive field before the export
        why: Hashes are fixed-length hex strings, so card and address validation code would fail; hashing does not preserve format.
    D. Restricting the export to developers who have signed an NDA
        why: An NDA is an administrative control that still allows real PII into development, which the compliance requirement forbids.
TAKEAWAY: Masking = realistic, format-preserving fake data for non-production use. Tokenization keeps a reversible lookup; hashing is one-way and not format-preserving.

[a010] type=mc domain=4 obj=4.5 (Given a scenario, modify enterprise capabilities to enhance security) cat=ops
Q: A hospital's mail administrator reviews the TXT record below after users report that spoofed messages claiming to come from the hospital's domain are being delivered to patients. Which of the following changes would BEST reduce successful spoofing of the domain?
EXHIBIT:
    hospital.example    IN TXT  "v=spf1 ip4:203.0.113.0/24 include:mailrelay.example.net ~all"
    _dmarc.hospital.example   (no record found)
  * A. Publish a DMARC record with a reject policy and add DKIM signing
        why: SPF alone only produces a soft fail (~all) and has no policy telling receivers what to do. DMARC with p=reject instructs receivers to discard unaligned mail, and DKIM adds a signature that survives forwarding.
    B. Change the SPF mechanism from ~all to +all
        why: +all authorizes every host on the internet to send as the hospital, which would make spoofing trivial rather than harder.
    C. Remove the include mechanism from the SPF record
        why: The include authorizes the hospital's legitimate relay provider; removing it would cause the hospital's real mail to fail SPF while doing nothing about spoofers.
    D. Add a wildcard MX record pointing to the hospital's mail server
        why: MX records control where inbound mail is delivered; they have no role in authenticating outbound mail or telling receivers to reject forgeries.
TAKEAWAY: SPF says which servers may send; DKIM signs the message; DMARC tells receivers what to do when both fail and where to send reports. Without DMARC, SPF results are advisory.

[a011] type=mc domain=2 obj=2.2 (Explain common threat vectors and attack surfaces) cat=social
Q: A school district's payroll clerk receives a call from someone who says they are with the district's IT help desk, explains that the clerk's account is being migrated, and asks the clerk to approve the MFA prompts that are about to appear on their phone. Which of the following BEST describes this attack?
  * A. Vishing combined with an MFA fatigue push
        why: A voice call using a fabricated IT pretext is vishing, and asking the victim to approve incoming prompts is the attacker pushing MFA notifications from a stolen password to get one accepted.
    B. Smishing
        why: Smishing is delivered by SMS text message. This attack arrived as a phone call, and the MFA prompts are push notifications, not texts.
    C. Business email compromise
        why: BEC uses a compromised or spoofed email account to request payments or data. No email is involved here, and the goal is account access, not a payment.
    D. Watering hole attack
        why: A watering hole compromises a website the target group visits. This attack contacts the victim directly by phone.
TAKEAWAY: Vishing = voice phishing. Coaching a victim to accept MFA prompts is the social side of an MFA fatigue attack; number matching and training defeat it.

[a012] type=mc domain=5 obj=5.2 (Explain elements of the risk management process) cat=gov
Q: A software company's board has directed that new products may be launched only after all high-severity findings are fixed, even if it delays revenue. A competitor ships faster and accepts more residual risk. Which of the following BEST describes the software company's stance?
  * A. Conservative risk appetite
        why: Refusing to launch with known high-severity risk, even at the cost of revenue, is a conservative appetite: the board is willing to trade speed for lower residual risk.
    B. Expansionary risk appetite
        why: An expansionary appetite accepts higher risk to grow faster; that describes the competitor, not this company.
    C. Risk avoidance
        why: Avoidance would mean not building the product at all. The company still ships, just after remediation.
    D. Risk transference
        why: Transference shifts financial impact to another party such as an insurer. No third party is taking on the risk here.
TAKEAWAY: Risk appetite is the amount of risk an organization is willing to pursue: expansionary (more), neutral, or conservative (less). Strategies (avoid, transfer, mitigate, accept) are how you treat a specific risk.

[a013] type=mc domain=4 obj=4.3 (Explain various activities associated with vulnerability management) cat=ops
Q: A software company's vulnerability scanner reports the finding below on a build server. The administrator confirms that the server is on the internal network only, runs the patched vendor package with backported fixes, and the service is reachable only from the build subnet. Which of the following should the administrator do FIRST?
EXHIBIT:
    Host: build02 (10.20.4.15)
    Plugin: Apache HTTP Server 2.4.x < 2.4.58 Multiple Vulnerabilities
    CVE-2023-45802   CVSS v3.1 Base: 7.5 (High)
    Detected version: 2.4.52 (from banner)
    Service: tcp/8080
  * A. Document the finding as a false positive and submit it for exception review with the evidence
        why: The scanner keyed on a banner while the distro backported the fix, so the vulnerability is not actually present. Confirmation and documentation come before any remediation effort.
    B. Upgrade the server immediately because the CVSS score is High
        why: CVSS measures theoretical severity, not whether the flaw exists here. Upgrading a system that is already fixed wastes a change window and skips the analysis step.
    C. Move the build server to the screened subnet to reduce exposure

        why: The threshold here is expressed in hours of downtime, a key risk indicator trigger, not a dollar limit on annual loss.

        why: Investigating a vendor's stability, security posture, and potential conflicts of interest before entering an agreement is the due diligence step of vendor selection.
    B. Vendor monitoring
        why: Monitoring is the ongoing review of a vendor after the contract is signed, such as tracking SLA performance and re-assessing periodically.
    C. Right-to-audit clause
        why: A right-to-audit clause is a contract term granting future inspection rights; the company is doing pre-contract research, not exercising a clause.
    D. Rules of engagement
        why: Rules of engagement define the scope and limits of a penetration test, not the evaluation of a prospective vendor.
TAKEAWAY: Vendor selection = due diligence (research before signing, including conflict-of-interest checks). Vendor monitoring = ongoing oversight after signing. Due care = acting on what you learned.
